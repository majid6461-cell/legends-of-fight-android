# افسانه‌های مبارزه — LEGENDS OF FIGHT

این پوشه یک پروژهٔ اولیهٔ بازی مبارزه‌ای سه‌بعدی با موتور **Godot 4.7.2** و زبان GDScript است. تمرکز این تحویل، ساخت یک نمونهٔ اولیهٔ قابل توسعه با منوها و سیستم مبارزه است، نه ادعای تحویل یک بازی تجاری کامل.

## قابلیت‌هایی که در کد این نسخه پیاده‌سازی شده‌اند

- ۱۲ پروفایل مبارز با نام، سبک، رنگ‌بندی و ویژگی‌های متفاوت؛
- ۸ میدان مبارزه با هندسهٔ سه‌بعدی ساده و اختصاصی که هنگام اجرا ساخته می‌شوند؛
- انتخاب شخصیت بازیکن اول و دوم و انتخاب میدان؛
- مبارزهٔ تک‌نفره با هوش مصنوعی در سه درجهٔ سختی؛
- بازی دونفرهٔ محلی روی یک گوشی با کنترل‌های لمسی مجزا؛
- تورنمنت ده‌مرحله‌ای و حالت تمرین؛
- نوار سلامتی و انرژی، دفاع، پرش، مشت، ضربهٔ سنگین، لگد، حرکت ویژه و حرکت نهایی؛
- Hitbox کروی و Hurtbox از نوع Area3D؛
- منوی فارسی با گزینهٔ زبان انگلیسی؛
- Workflow برای ساخت APK در GitHub Actions.

## اجرای پروژه روی کامپیوتر

۱. نسخهٔ Godot **4.7.2 Stable** را نصب کنید.
۲. فایل `project.godot` را از Godot باز کنید.
۳. پس از پایان Import، کلید F6 یا F5 را بزنید.
۴. حالت بازی، مبارزان و میدان را انتخاب کنید.

## ساخت APK

در رایانه باید Java 17، Android SDK و Export Templates متناظر با Godot 4.7.2 نصب باشد. سپس:

```bash
godot --headless --editor --import --path . --quit
godot --headless --path . --export-debug "Android" build/LegendsOfFight.apk
```

در GitHub، یک مخزن خالی با نام `legends-of-fight-android` بسازید و محتوای این پوشه را به شاخهٔ اصلی آن Push کنید. سپس از مسیر **Actions → Build Android APK → Run workflow**، ساخت را اجرا کنید. پس از موفقیت، فایل `LegendsOfFight.apk` در قسمت Artifacts قابل دریافت است. با Push کردن Tag مانند `v0.1.0`، Workflow علاوه بر Artifact، فایل APK را به Release نیز پیوست می‌کند.

## محدودیت‌های این نسخه

مدل‌ها از قطعات هندسی کم‌جزئیات و انیمیشن آن‌ها رویه‌ای هستند؛ هنوز مدل شخصیت حرفه‌ای، اسکلت و انیمیشن‌های سینمایی، موسیقی و صداهای اختصاصی، ذخیرهٔ پیشرفت و اقتصاد آزادسازی مبارزها ساخته نشده‌اند. فیلد آزادسازی در اطلاعات مبارزان فعلاً دادهٔ آماده برای توسعهٔ بعدی است و قفل واقعی اعمال نمی‌کند. کیفیت گرافیک فعلاً نور و سایهٔ صحنه را کنترل می‌کند.

**وضعیت ساخت:** سورس و Workflow آماده شده‌اند؛ APK در این محیط ساخته و روی شبیه‌ساز یا گوشی آزمایش نشده است. گزارش دقیق در `docs/TEST_REPORT.md` قرار دارد.
